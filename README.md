Sizzle Line: Rush Hour Kitchen — a complete, original cooking game that plays offline in a desktop browser from static files. You are the chef on a 90-second shift: tickets land on the order board with countdown timers, you run between the ingredient bins, the grill, the chopping board and the plating counter, and you serve matching plates at the window before the ticket expires. Five named recipes (Classic Stack, Cheese Melt, Garden Fresh, The Works, Double Trouble), two rush levels that speed the tickets up, combos that pay more the longer you serve cleanly, and a star-rated shift report at the end.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with WASD / arrow keys or the mouse; E or Space picks up, grills, chops, plates and serves. Press Enter to start a shift.
